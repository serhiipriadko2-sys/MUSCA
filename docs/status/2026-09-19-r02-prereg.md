## Target claim

R02 is deliberately narrower than “reproduce Figure 1”.
It tests one published prediction that is common across the source lineage:

> Under unilateral sugar-GRN activation, the contralateral MN9 is driven more
> strongly than the ipsilateral MN9.

The frozen condition is **200 Hz**, 30 trials, 1000 ms per trial, for both the
archived right-hemisphere and left-hemisphere sugar-GRN sets.

This condition removes the tutorial-default conflict because the figure recipe
explicitly sets `params['r_poi'] = 200 * Hz`; neither 150 Hz nor prose default
controls the experiment.

## Source conflict map

main Figure 1c and the right-hemisphere condition to Extended Data Figure 1d.

[FACT] The archived/preprint `figures.ipynb` labels Figure 1 using the 21-neuron
right set and Figure S1 using the 10-neuron left set.
[FACT] The archived Edmond V3 `figures.ipynb` cell sources are semantically
identical to the pinned GitHub snapshot used by MUSCA, even though the notebook
bytes differ by one byte.

[DECISION] R02 does **not** preregister panel identity as the claim.
It preregisters the bilateral 200 Hz laterality direction, so the source-label
conflict cannot be resolved by silently choosing the more convenient panel name.

## Primary success gate

R02 is PASS only if **both** hemisphere conditions:
1. complete all 30 trials with structurally valid output;
2. have contralateral MN9 mean > ipsilateral MN9 mean;
3. have one-sided Mann–Whitney `p < 0.05`;
4. retain at least 50% of the archived MN9 mean-difference effect;
5. have archived-vs-rerun whole-neuron mean-rate Spearman `rho >= 0.98`.

These thresholds are fixed before local R02 execution.

Absolute MN9 means, top-200 Jaccard, wall time and RAM are secondary diagnostics.
They cannot rescue failure of a primary criterion.
