## Финальный артефакт и отдельная проверка

Путь: `experiments/results/gate-p01-build.zip`. Команды:

```powershell
py -3.14 scripts/pilot_bundle.py freeze --output experiments/results/gate-p01-build.zip
py -3.14 scripts/pilot_bundle.py verify experiments/results/gate-p01-build.zip
```

Отдельная проверка извлекает только собственный только что созданный архив
после сверки внешнего SHA-256 в новый временный каталог, выполняет полный
набор тестов и химический сценарий, затем сохраняет точный результат, среду,
время и внешний SHA-256 в `experiments/results/gate-p01-build.verification.json`.
Этот внешний файл — квитанция конкретного архива; он не включён внутрь ZIP,
чтобы не создавать циклическую зависимость хеша от собственной квитанции.

`tests=not_run_by_packager` внутри ZIP не означает провал: упаковщик не имеет
права приписывать себе отдельный запуск тестов. Смотрите внешний результат.
Сам архив и квитанция исключены из Git. Отправки по сети и публикации нет.

## Границы

Проверка хешей без доверенного внешнего хеша не доказывает авторство.
Архив не защищён от удаления и не является внешней резервной копией.
Python 3.14.6 должен быть установлен отдельно. Другие ОС, CI, GitHub и Remote
Desktop Commander в этом этапе повторно не проверялись. Условия участия и
хранения данных должны быть согласованы с реальными участниками до сбора;
упаковщик не заменяет это действие. Биологическая гипотеза остаётся непроверенной.

∆ — исходники и протокол можно сохранить и проверить как единый снимок.
D — 14 новых тестов, 75 в общей сборке, внешний след конкретного ZIP.
Ω — PASS относится к локальной воспроизводимости, не к результатам пилота.
Λ — новый код/протокол требует нового снимка; вывод об игре требует реальных сессий.
