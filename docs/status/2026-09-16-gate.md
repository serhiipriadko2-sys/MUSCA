Дата: 2026-09-16. Продолжение [технического аудита](2026-09-16-audit.md).
Режим BUILD. Объём: один локальный игровой этап, без научного эксперимента.

## Изменённые файлы

- `musca/puzzle.py` — скрытые свойства мира, наблюдение, ресурс, решение и исход.
- `musca/contracts.py`, `musca/bridge.py`, `musca/interpretation.py` — проверяемая
  телеметрия шлюза, перевод в события и пересмотр гипотезы по наблюдению.
- `musca/__main__.py` — `--puzzle`, `--layout`, ввод человека и квитанция.

- `docs/adr/ADR-0004-terminal-gate-puzzle.md`, `docs/PLAYTEST_PROTOCOL.md`,
  `experiments/manifests/gate-p01.json` — решение, протокол и план назначений.
- `README.md`, `docs/GAME_VISION.md`, `docs/PROJECT_CHARTER.md`,
  `docs/status/CURRENT.md` и эта квитанция — актуальное описание этапа.

Старые изменения сохранены. Новых зависимостей, глобальных настроек и внешних
сервисов нет. Ветка `docs/musca-foundations`, код ещё не закоммичен. Подписанные
исследовательские выводы и фактические ответы игроков не создавались.

## Команды и артефакты

```powershell
py -3.14 -m unittest discover -s tests -p test_puzzle.py -v
py -3.14 -m unittest discover -s tests -q
git diff --check
```

Для двух дополнительных прогонов в stdin переданы `go`, `scan` и выбранный
по условиям фикстуры реагент. Команды:

```powershell
py -3.14 -m musca --puzzle --mode light_chemical --layout a --output experiments/results/gate-v1-developer-a.json
py -3.14 -m musca --puzzle --mode light_chemical --layout b --output experiments/results/gate-v1-developer-b.json
```

Оба выхода — 0; 4 тика навигации, 0 столкновений, `opened`, остаток 1 ячейка.
Это `developer_check`: не включать в GATE-P01. Значение `input_mode=human`
обозначает интерактивный путь CLI, а не доказанное участие человека.
Обе локальные квитанции содержат фактические runtime-хеши, среду, время и
старый базовый commit с `worktree_dirty=true`; файлы исключены из Git.

## Остаточные риски

Идеальная проба может превратить выбор в обязательное нажатие; ограниченность
светового режима может вызвать угадывание. Устранение этих рисков нельзя
объявить по автотестам. Пилот имеет 12 назначений и заранее выбранные продуктовые
пороги, не статистическую мощность для вывода о популяции. Состав искусственный,
модель химии и нейронная динамика отсутствуют.

Предметное наблюдение шлюза — отдельная сценарная часть мира через Bridge.
`MuscaBackend` заменяем для навигации; нейронное восприятие реагентов не реализовано.
Интерпретатор читает события; доступность исходников/диагностического JSON всё же
позволяет человеку узнать ответ. Поэтому ведущий скрывает их до конца пилота.

Никаких игровых сессий, приглашений, сетевых записей, commit, push или CI-запусков
не выполнялось. GitHub, Remote Desktop Commander и внешние статьи в этом этапе
повторно не проверялись: новых внешних предпосылок и зависимостей не вводилось.
Предыдущие результаты этих проверок не объявляются проверкой новой сборки.
