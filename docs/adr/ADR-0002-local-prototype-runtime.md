# ADR-0002: среда первого исполняемого прототипа

## Status

Выбрано для ограниченного локального технического прототипа после команды
пользователя «продолжай». Не определяет окончательный язык проекта, игровой
движок или научный симулятор. Проверки реализации фиксируются отдельно в
[текущем статусе](../status/CURRENT.md).

## Context

Следующий шаг [манифеста](../PROJECT_CHARTER.md) — проверить заменяемый нижний
контроллер и отдельный Bridge в воспроизводимом сценарии. Графика, реальные
нейроны, сеть и большой датасет для этой проверки не нужны.

## Decision

Использовать установленный CPython 3.14 и только стандартную библиотеку.
Точную версию локальной проверки закрепить в `.python-version` и квитанциях
запуска. Команды запуска не устанавливают и не обновляют Python.

Мир — целочисленная сетка с четырьмя направлениями движения и фиксированным
шагом времени. Один шаг равен одному условному тику, без перевода в биологические
секунды. Непроходимые клетки блокируют движение. Сенсоры читают текущую клетку
и четыре соседние; никаких координат источника контроллер не получает.
Это собственная маленькая тестовая модель, не физический движок.

Терминал предоставляет человеку семантические решения: исследовать или ждать.
Для автоматической проверки доступен повтор того же сценария с записанным
намерением. Вывод JSON включает наблюдения, гипотезы, решения и последствия;
отладочные координаты отделены от информации интерпретатора.

## Alternatives

| Вариант | Цена и причина решения |
| --- | --- |
| Python и стандартная библиотека | Достаточно для небольшого стенда; выбрано. Нет графического интерфейса и оснований ожидать пригодности для большой нейросети. |
| JavaScript в браузере | Можно сразу проверять визуальный интерфейс; сейчас это добавляет отдельную задачу представления и тестирования. Оставлен для будущего игрового этапа. |
| Игровой движок | Помогает полноценному игровому срезу, но требует отдельной проверки зависимости и связывает первый контракт с большей средой. Выбор отложен. |

## Evidence

Наблюдение 2026-09-16: `py -3.14 --version` возвращает `Python 3.14.6` на этой
Windows-машине. Это локальное свидетельство, не утверждение о последнем релизе.

Первичные источники проверены 2026-09-16:

- [dataclasses](https://docs.python.org/3.14/library/dataclasses.html) описывает структуры
  с аннотациями и режим `frozen`; аннотации сами не валидируют значения.
- [typing.Protocol](https://docs.python.org/3.14/library/typing.html#typing.Protocol)
  описывает структурный интерфейс, используемый для замены backend.
- [unittest](https://docs.python.org/3.14/library/unittest.html) предоставляет проверки
  без стороннего тестового пакета.
- [Python на Windows](https://docs.python.org/3.14/using/windows.html) описывает выбор
  версии через `py`; локальный запуск дополнительно проверен командой.
- [Лицензия](https://docs.python.org/3.14/license.html),
  [цикл выпуска 3.14](https://peps.python.org/pep-0745/) и
  [политика безопасности](https://www.python.org/dev/security/) — основания
  проверки происхождения, сопровождения и обработки уязвимостей среды.

## Consequences / price

Gate зависимости: цель — стенд; лицензия — PSF с перечисленными в документации
компонентами; сопровождение — ветка 3.14 по опубликованному циклу; платформа —
локально проверенная Windows. Сторонних пакетов, GPU, CUDA, Docker и WSL не нужно.
Сканирование всех уязвимостей установленного интерпретатора не проводилось;
наличие официальной политики не доказывает отсутствие уязвимостей.

Стоимость ограничена уже установленным интерпретатором и малыми исходниками.
Производительность большой модели не измерена. Файл блокировки пакетов не нужен:
разрешаемых сторонних зависимостей нет. При их появлении потребуется новый gate
и соответствующий lockfile. Замена среды потребует переноса маленькой сетки и
контрактных тестов; интерфейс сети или игры этим ADR не закрепляется.

## Tests

До заявления о работающем стенде проверить: детерминированное воспроизведение;
замену backend на неподвижный; обход препятствий; различие наблюдений режимов;
честную остановку при ошибке или истечении намерения; полный цикл CLI.
Критерии границы Bridge — в [ADR-0003](ADR-0003-bridge-contract.md).

## Diff scope

`musca/`, `tests/`, `.python-version`, исключения Python-кеша в `.gitignore`,
обновления README и статуса. Никаких глобальных установок или внешних записей.

## Rollback

Пересмотреть эту ограниченную среду новым ADR. Сохранить сценарий и тесты как
спецификацию поведения; не переносить автоматически технические ограничения
сетки в будущую игровую или биологическую модель.

## ΔDΩΛ

∆ — выбран минимальный локальный стенд без сторонних зависимостей.
D — локальный Python и проверенные первичные документы.
Ω — выбор достаточен для контрактного теста; научная и игровая пригодность неизвестны.
Λ — пересмотреть при необходимости графики, непрерывной физики или нейронной динамики.
